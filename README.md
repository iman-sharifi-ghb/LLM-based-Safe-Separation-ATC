# LLM-based-Safe-Separation-ATC
We explore the use of Large Language Models (LLMs) to enhance safe separation in Air Traffic Control (ATC) while improving generalizability of the decision-making system. The approach is structured into several key stages, combining supervised learning, symbolic verification, retrieval-based augmentation, and reinforcement learning.
